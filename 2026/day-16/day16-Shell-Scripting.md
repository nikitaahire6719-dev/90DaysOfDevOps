# 🚀 Day 16 – Shell Scripting Basics

## 📌 Overview

Completed Day 16 of the **#90DaysOfDevOps** challenge by learning the fundamentals of Bash Shell Scripting and writing basic automation scripts.

## ✅ Tasks Completed

### Task 1 – First Shell Script

* Created `hello.sh`
* Added the shebang (`#!/bin/bash`)
* Executed the script using execute permissions
* Learned the purpose of the shebang

### Task 2 – Variables

* Worked with variables
* Used `echo` to display variable values
* Learned the difference between single (`' '`) and double (`" "`) quotes

### Task 3 – User Input

* Used `read` and `read -p` to accept user input
* Created `greet.sh` to display personalized greetings

### Task 4 – Conditional Statements

* Learned `if`, `then`, `else`, and `fi`
* Created `check_number.sh`
* Created `file_check.sh` using the `-f` operator to verify file existence

### Task 5 – Combining Concepts

* Created `server_check.sh`
* Used `systemctl is-active` to check service status
* Learned how to use command exit status (`$?`) for decision-making

## 📚 Key Concepts Learned

* Shebang (`#!/bin/bash`)
* Variables and variable expansion (`$variable`)
* `echo`, `read`, and `read -p`
* Conditional statements (`if`, `then`, `else`, `fi`)
* Numeric comparison operators (`-gt`, `-lt`, `-eq`, `-ge`, `-le`, `-ne`)
* File test operator (`-f`)
* Exit status (`$?`) and its role in Bash scripting

## 🛠 Scripts Created

* `hello.sh`
* `variable.sh`
* `greet.sh`
* `check_number.sh`
* `file_check.sh`
* `server_check.sh`

## 🎯 Outcome

This day helped me understand the basics of Bash scripting, user interaction, conditional logic, file validation, and command exit status, which are essential building blocks for Linux automation and DevOps.
